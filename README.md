# construction-contract
공사계약자동화시스템

## 웹에서 사용

[공사계약 업무 자동화 앱](https://commetee12-source.github.io/construction-contract/)

GitHub Pages가 `main` 브랜치의 루트 폴더를 배포합니다. 변경사항을 `main`에
푸시하면 같은 주소에 자동 반영됩니다.
로컬 앱에서 저장한 입력정보는 웹 주소로 자동 이전되지 않습니다. 로컬 앱에서
**입력정보 저장** 후 배포된 앱에서 **입력정보 불러오기**를 이용하세요.

## 실행

`index.html`을 Chrome 또는 Edge에서 엽니다. 서버, 계정, 인터넷 연결 없이
기본 기능을 사용할 수 있습니다. 법령 링크에는 인터넷 연결이 필요합니다.
`index.html`, `assets`, `공사계약_구비서류`, `원클릭 프로그램(2026.5.수정)`은
같은 폴더 구조로 보관합니다.

## 원클릭 프로그램 반영

- **원클릭 서류 작성**: 공사 32종, 설계용역 21종. 각각 서울시교육청용과 타기관용을 선택합니다.
- 공통정보를 한 번 입력하면 원본 서식의 금액, 보증금, 날짜와 문구를 다시 계산합니다.
- 미리보기에서 공통정보·수식 이외의 기존 문구를 클릭하여 서식별로 수정할 수 있습니다.
- 선택한 여러 서식을 한 번에 인쇄합니다. Chrome 인쇄창에서 **PDF로 저장**을 선택할 수 있습니다.
- **설계용역비 산출**: 건축·토목·설비·전기·통신·냉난방을 지원합니다. 결과를 설계용역 서류의 계약금액으로 전달할 수 있습니다.
- 계약 절차의 구비서류 탭에서도 해당 서식의 **원클릭 작성** 버튼을 이용할 수 있습니다.

입력정보는 사용하는 브라우저의 로컬 저장소에 저장됩니다. **입력정보 저장**으로 JSON 파일을
내보내고 **입력정보 불러오기**로 복원할 수 있습니다. JSON에는 입력한 업체·계좌 정보가 포함됩니다.
브라우저·파일 위치를 바꾸기 전에는 입력정보를 파일로 보관하세요.

### 적용 범위와 원본

제공된 `원클릭 프로그램(2026.5.수정)`의 XLSM 5개를 읽어 웹 기능으로 이식했습니다.
원본 엑셀은 수정하지 않았으며 각 화면에서 내려받을 수 있습니다. Excel VBA를 브라우저에서
실행하는 방식은 아닙니다. 시트의 셀·병합·글꼴·테두리를 HTML 인쇄 서식으로 변환했으며
도형·매크로 버튼·이미지를 그대로 재현하지는 않습니다. 원본에서 삭제·숨김 처리한 공사 서식은 목록에서 제외했습니다.

계산식·요율표는 제공된 파일의 기준입니다. 원본의 계약보증금 특례 안내는 2026.6.30.까지로
표기되어 있으며, 이후 연장 여부는 이번 확인에서 확정하지 못했습니다. 보증금률과 보험·공제 요율은
자동 확정하지 않고 직접 선택·입력하도록 했습니다. 냉난방 노임단가의 기본값은 원본의 2025년 값이며 수정 가능합니다.
현행 규정 확인은 [국가법령정보센터](https://www.law.go.kr/)를 이용하세요.

설계용역 각서의 다른 엑셀 파일 참조 오류는 업체명·대표자·기관명에 맞춰 현재 입력 시트로
연결했습니다. 해당 각서의 고정 예시 날짜도 입력한 계약일로 연결했습니다.
원본 VBA의 설계비 배분율 0.0001 증가 반복은 정수 단계로 구현하여 누적 오차와 무한 반복을 방지했습니다.

## 검증 및 유지보수

계산 로직 검증: `node --test tests/oneclick.test.cjs`

`tests/oneclick-browser.js`는 Playwright CLI의 `run-code --filename`에 전달하는 브라우저 검증입니다.
파일 선택 대화상자가 열리면 CLI의 `upload` 명령으로 검증용 입력 파일을 전달합니다.
검증 자료는 `output/playwright`에 저장하며 실제 입력정보와 분리됩니다.

`tools/extract_oneclick.py`는 원본을 읽어 `assets/oneclick-data.js`를 생성하는 유지보수 도구입니다.
Python과 openpyxl이 필요하며, 웹앱 실행에는 필요하지 않습니다. 이 도구는 매크로를 실행하지 않습니다.
